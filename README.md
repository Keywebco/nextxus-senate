# NextXus Senate

The public page for the Federation Senate: the deliberative body that governs Federation legislation, disputes, and policy. It is for anyone who wants to know what the Senate is, what it stands on, and how it works.

**Live:** https://keywebco.github.io/nextxus-senate/

## What's on the page

- **What the Senate is** — the deliberative body governing legislation, disputes, and policy.
- **The governing principles** — Truth Before Comfort, Legacy Before Ego, Give Without Reward.
- **Membership** — how seats in the Senate are held.
- **How the Senate deliberates** — the debate process.
- **The Charter** — the founding document.

## Notes

- Single static page (`index.html`) — an informational document, no interactive tooling.
